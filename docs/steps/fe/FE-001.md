# FE-001 — Tailwind v4 토큰 셋업

## 목표

prototype 의 모든 CSS 변수 (`--bg`, `--surface`, `--ink`, `--muted`, `--hint`, `--line`, `--chip`, `--blue`, `--blue-pressed`, `--blue-soft` 등)를 Tailwind v4 의 `@theme` 으로 옮겨, `bg-bg`, `text-ink`, `bg-brand-500` 같은 유틸리티가 활성화된다. 디자인 토큰 1대1 보존을 단위 테스트로 검증.

## 사전 조건

- BOOT-000 완료 (frontend 빈 프로젝트 + Tailwind v4 설치 상태)

## 파일 대상

```
frontend/app/globals.css                                          [수정]
frontend/__tests__/tokens.test.ts                                 [신규]
frontend/vitest.config.ts                                          [수정/신규 — 환경 jsdom]
frontend/package.json                                             [수정 — vitest 의존성]
```

## 테스트 명세

- **테스트 파일**: `frontend/__tests__/tokens.test.ts`
- **테스트 이름**: `globals_css_defines_all_prototype_tokens`
- **given**: `app/globals.css` 의 텍스트
- **when**: 파일을 fs 로 읽어 정규식으로 `--color-*`, `--font-*`, `--radius-*` 변수 추출
- **then**: 다음 토큰명·값이 모두 존재
  - `--color-bg: #f2f4f6`
  - `--color-surface: #ffffff`
  - `--color-ink: #191f28`
  - `--color-muted: #6b7684`
  - `--color-hint: #8b95a1`
  - `--color-line: #e5e8eb`
  - `--color-chip: #f2f4f6`
  - `--color-brand-50: #fff0e7`
  - `--color-brand-500: #ff8a3d`
  - `--color-brand-600: #f97821`
  - `--color-economy: #4f9cf9`
  - `--color-social: #9b7cf8`

## 구현 힌트

- `app/globals.css` 상단에 `@import "tailwindcss";`
- `@theme { --color-bg: #f2f4f6; ... }` 블록
- 기존 docs 의 [frontend/tailwind.md](../../frontend/tailwind.md) §v4 설정 방식 그대로 복사
- Pretendard `@font-face` 도 같이 정의 (값 출처 [design.md](../../design.md) §2.3)
- vitest 셋업:
  ```bash
  pnpm add -D vitest @vitest/ui
  ```
- 테스트에서 Node fs API 사용 (`readFileSync('./app/globals.css')`)

## 검증 방법

**자동**:
```bash
cd frontend
pnpm test
```
기대: `tokens.test.ts` 1 test pass.

**수동**:
```bash
cd frontend
pnpm dev
# 브라우저에서 http://localhost:3000 열고 dev tools 콘솔에서:
getComputedStyle(document.documentElement).getPropertyValue('--color-brand-500').trim()
# 기대 출력: "#ff8a3d"
```
